# Google Antigravity Home Assistant Add-on

Google Antigravity (`agy`) AI coding assistant and `remote-control` daemon with a persistent `tmux`-backed Ingress TUI and Home Assistant OS toolchain (`ha`, `docker`, `uv`, `rg`, `gh`, `sqlite3`, `mosquitto-clients`).

See [DOCS.md](DOCS.md) for full configuration and usage details.
