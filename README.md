# Google Antigravity Home Assistant Add-on Repository

Official Home Assistant Add-on repository for **Google Antigravity CLI (`agy`)**.

## Add-ons in this Repository

- **Google Antigravity CLI**: Development environment, Ingress terminal, and always-turbo remote-control daemon.

## Installation

1. In Home Assistant, navigate to **Settings > Add-ons > Add-on Store**.
2. Click the **three dots** in the top right corner and select **Repositories**.
3. Add this repository URL:
   ```
   https://github.com/mostlyrobots/agy-ha
   ```
4. Scroll down (or search) for **Google Antigravity CLI**, click **Install**, and turn on **Show in sidebar**.
5. Start the add-on and open **Antigravity** in the sidebar to authenticate. Once logged in, the remote-control server starts automatically in background turbo mode.
